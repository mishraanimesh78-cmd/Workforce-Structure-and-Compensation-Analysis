# Workforce-Structure-and-Compensation-Analysis
This project contains a series of SQL queries designed for a Workforce Analytics internship task. The goal is to support a Human Resources department by extracting insights from a normalized database regarding employee compensation, departmental structure, and career progression.

📊 Project Highlights Database
 Schema: Utilizes a multi-table relational structure including employees, departments, salaries, titles, and dept_manager.
Key Focus: Data extraction for HR decision-making, compensation auditing, and organizational mapping.
Technical Skills:
      DDL/DML operations Complex Joins (INNER, LEFT)Aggregate Functions (AVG, COUNT, MAX, etc.)
Data Filtering & Grouping (WHERE, GROUP BY, HAVING)

📂 Repository Structure
SQL Scripts:
 Executable .sql files containing solutions to 20 specific business questions.

Analysis Areas:
Salary benchmarks and averages by department.
Managerial hierarchies and tenure tracking.
Gender distribution and workforce growth (hiring trends).

🛠️ Tools Used
Language: SQL (MySQL / PostgreSQL compatible)
